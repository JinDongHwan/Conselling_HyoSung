# 법률 검토 체크리스트 — 나이 정책·보호자 동의

magic.ai는 2026-10-06부터 청소년(만 19세 미만)을 **학교·기관 가입 코드로만** 받는다. 아래는 코드에 반영했지만 법률 검토로 확정해야 하는 항목이다. 코드에서는 `TODO(법률 검토)`로 표시해 두었다.

## 현재 구현된 정책
| 구분 | 가입 경로 | 동의 | 상담 이용 |
|---|---|---|---|
| 만 19세 이상 | 개인 가입 또는 기관 코드 | 본인: 이용약관·개인정보·민감정보(필수), 관리자 원문 열람(선택) | 바로 가능 |
| 만 14~18세 | **기관 코드만** (기관이 청소년 허용한 경우) | 본인: 청소년용 쉬운 문구로 같은 3가지 | 바로 가능 |
| 만 14세 미만 | **기관 코드만** (기관이 14세 미만 허용한 경우) | 본인 안내 + **보호자 동의** | 보호자 동의 확인 후 |

- 보호자 동의 방법: ① 보호자 동의 링크(14일 유효)로 이름·관계·연락처와 동의 제출 → 운영자가 연락처로 확인 후 "확인 완료" ② 학교·기관에서 받은 서면 동의서를 운영자가 확인해 기록
- 기록: 동의 항목별 시각, 약관 버전, 보호자 동의 상태(요청·제출·완료·거절·철회), 처리한 관리자, 관리 기록
- 보호자에게 상담 원문은 자동 공개하지 않음
- 만 19세 미만은 관리자 원문 열람 동의를 받지 않고, 위기(높음) 대화만 관리자가 확인
- 위기 신호(자해·자살·학대·폭력) 감지 시 AI 답변 대신 고정 안내 (청소년: 1388·109·112·117·119)

## 확인이 필요한 항목
1. **법정대리인 동의 확인 방법** — 개인정보 보호법 제22조의2, 시행령 제17조의2에 비추어 ①(링크 제출 + 운영자 연락 확인), ②(학교 서면 동의서) 방식이 충분한지. 휴대폰 본인인증·문자 확인 연동이 필요한지.
2. **학교·기관과 회사의 역할** — 학교가 개인정보처리자이고 회사가 수탁자인지, 각자 처리자인지. 위탁 계약서·개인정보처리방침 문구에 반영.
3. **보호자 동의 확인 자료 보관** — 보호자 이름·관계·연락처, 서면 동의서 사본의 보관 기간과 파기 시점 (현재: 자녀 탈퇴 시 삭제).
4. **보호자에게 제공할 정보의 범위** — 법정대리인의 열람 요청 시 상담 원문까지 제공해야 하는지, 자녀 보호를 위해 제한할 수 있는지.
5. **위기 상황 대응과 신고 의무** — 학대·폭력 의심 시 회사 또는 학교의 신고 의무(아동학대처벌법 신고의무자 해당 여부), 보호자·학교에 알리는 기준.
6. **상담자 역할과 자격 표시** — AI 상담의 범위, 기관 상담교사·상담사의 역할 표시 방법, "상담" 용어 사용의 적정성.
7. **미성년자 유료 계약** — 유료 기능 도입 시 민법상 법정대리인 동의 절차 (현재 결제 없음).
8. **청소년용 자가진단 도구** — PHQ-9·GAD-7은 성인용. 청소년용 검증 도구(예: PHQ-A)와 사용 허가.
9. **학교 납품 요건** — 학교운영위원회 심의용 개인정보 체크리스트, 조달 등록, 클라우드 보안 요건.
